## 一、网络模型基础

## 1. OSI 七层模型（重点理解）

口诀（原笔记保留）：
 **应表会传网数物**

| 层级 | 名称       | 主要功能                  |
| ---- | ---------- | ------------------------- |
| 7    | 应用层     | 应用程序、原始数据        |
| 6    | 表示层     | 格式、压缩、加密          |
| 5    | 会话层     | 会话管理、全双工 / 半双工 |
| 4    | 传输层     | 分段、重组、端口号        |
| 3    | 网络层     | IP 地址、寻址、路由       |
| 2    | 数据链路层 | MAC 地址、局域网通信      |
| 1    | 物理层     | 传输介质、比特流          |

------

### 会话方式说明（原笔记）

- **半双工**：对讲机（单向通信）
- **全双工**：电话（双向通信）

------

| 数据链路层 |

------

## 二、数据单元（DU）

| 层级       | 数据单元         |
| ---------- | ---------------- |
| 应用层     | APDU（原始数据） |
| 传输层     | Segment（段）    |
| 网络层     | Packet（包）     |
| 数据链路层 | Frame（帧）      |
| 物理层     | Bit（比特）      |

------

## 三、封装与解封装（理解重点）

- **封装**：
   应用数据 → 加 TCP 头 → 加 IP 头 → 加 MAC 头
- **解封装**：
   从物理层逐层向上拆包

------

## 四、交换机与路由器（原理）

### 1. 交换机

- 基于 **MAC 地址**
- 维护 MAC 地址表
- 工作过程：学习 → 广播 → 单播 → 更新

------

### 2. 路由器

- 基于 **IP 地址**
- 负责不同网络之间通信

------

### 3. 地址对应关系（原笔记）

- MAC 地址 → 帧封装 → 交换机
- IP 地址 → 包封装 → 路由器

------

## 七、Web 服务：Apache

## 1. Apache 简介

- Web 服务软件
- 提供 HTTP 服务

------

### 2. 网站主目录

```
/var/www/html/
```

> 💡 注：
>  网站源码默认放在此目录下

------

## 3. 虚拟主机（VirtualHost）

### 示例：创建 `a.org` 网站

```
vim /etc/httpd/conf.d/a.org.conf
```

配置内容：

```
<VirtualHost *:80>
    ServerName www.a.org
    DocumentRoot /var/www/html/a.org
</VirtualHost>
```

------

### 4. 目录授权（重要）

当网站目录 **不在默认路径** 时，需要授权：

```
<Directory "/b.org">
    Require all granted
</Directory>
```

------

## 5. 域名解析（本地）

```
vim /etc/hosts
```

示例：

```
192.168.64.130   www.a.org
```

> 💡 注：
>  IP 填 Web 服务器地址

## 6. 启动与重启 Apache

```

```
