## 一、Linux 目录结构

Linux 系统中，一切皆文件，所有内容都从 `/`（根目录）开始。

### 1. 常见目录说明

- **/boot**
   启动目录，存放系统启动所需的关键文件（内核、引导文件）

- **/etc**
   系统与服务的**配置文件目录**

  > 💡 注：几乎所有服务的配置都能在这里找到

- **/home**
   普通用户的家目录

  > 每个用户通常对应一个 `/home/用户名`

- **/run**
   运行时文件（临时），系统重启后会清空

- **/bin**
   普通用户可使用的基础命令
   例如：`ls`、`cp`、`mv`

- **/sbin**
   超级用户（root）使用的系统管理命令

- **/tmp**
   临时目录，**所有用户都可写**，重启可能清空

- **/usr**
   应用程序目录（软件、库、共享资源）

- **/var**
   经常变化的文件
   如：日志（`/var/log`）、缓存等

## 二、ls 命令与文件类型

### 1. ls 常用用法

```
ls        # 列出当前目录内容
ls -l     # 以列表方式显示（权限、属主、大小等）
```

### 2. 文件类型标识（ls -l 开头）

- `-` ：普通文件
- `d` ：目录（通常显示为蓝色）

示例：

```
-rw-r--r--  普通文件
drwxr-xr-x  目录
```

## 四、目录与路径操作命令

### 1. cd —— 切换目录

```
cd 目录
```

常见用法：

- `cd /`：进入根目录
- `cd ~`：进入当前用户家目录
- `cd ..`：返回上一级目录

------

### 2. pwd —— 显示当前路径

```
pwd
```

------

### 3. 路径表示方式

- `./`：当前目录（可以不写）
- `../`：上一级目录
- `../../666.txt`：上上级目录下的文件

> 💡 注：路径是否以 `/` 开头，决定是**绝对路径**还是**相对路径**

------

## 五、文件与目录创建

### 1. 创建文件：touch

```
touch 文件名
touch /路径/文件名
```

------

### 2. 创建目录：mkdir

```
mkdir 目录名
```

常见用法：

- 创建多级目录（父目录不存在时自动创建）：

```
mkdir -p /父目录/子目录
```

- 同一目录下创建多个目录：

```
mkdir /home/{1,2}
```

- 创建嵌套目录：

```
mkdir /home/{1/{3,4},2}
```

------

## 六、查看根目录内容

```
ls /
```

作用：

- 查看系统整体目录结构
- 初学 Linux 非常重要的命令
