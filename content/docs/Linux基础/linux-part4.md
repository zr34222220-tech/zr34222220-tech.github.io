## 一、进程管理基础

### 1. 查看进程（任务管理器）

```
ps aux
```

查看前几行（表头 + 部分进程）：

```
ps aux | head -2
```

> 💡 注：
>
> - `a`：所有用户
> - `u`：显示用户
> - `x`：包括后台进程

------

### 2. 查看进程父子关系

```
ps -ef
```

字段说明：

- `PID`：进程 ID
- `PPID`：父进程 ID

------

## 二、进程状态

| 状态 | 含义               |
| ---- | ------------------ |
| R    | running（运行）    |
| S    | sleep（休眠）      |
| T    | stop（停止）       |
| Z    | zombie（僵尸进程） |

> 💡 注：
>  僵尸进程通常是**父进程未回收子进程资源**

------

## 三、进程信号控制（kill）

```
kill 信号 PID
```

常用信号：

- `-15`：正常终止（默认）
- `-9`：强制杀死（内存中擦除）

示例：

```
kill -15 1234
kill -9 1234
```

> ⚠️ 注：
>  `-9` 适用于**僵死程序**，不建议常用

------

## 四、进程优先级（nice）

### 1. nice 值说明

- nice 值范围：`-20 ~ 19`
- 值 **越小** → 优先级 **越高**
- 值 **越大** → 优先级 **越低**

映射关系（你原笔记保留）：

- PR -20 → 0
- PR +19 → 39

------

### 2. 查看进程优先级

```
ps axo pid,comm,nice --sort=-nice | head -5
```

说明：

- `axo`：自定义显示字段
- `--sort=-nice`：按优先级降序

------

### 3. 创建指定优先级进程

```
nice -n -5 sleep 7000 &
```

说明：

- `-n -5`：指定 nice 值
- `&`：后台运行

查看后台进程：

```
jobs
```

------

### 4. 修改进程优先级

```
renice -20 PID
```

------

## 五、kill 扩展用法

```
kill 1
```

- 杀死 PID = 1 的进程（极其危险）

```
kill %1
```

- 杀死后台编号为 1 的进程

------

## 六、重定向（I/O Redirect）

### 1. 输出重定向

```
date > time.txt
```

说明：

- 覆盖写入文件

------

### 2. 标准输出与错误输出

- 标准输出：`1>`
- 错误输出：`2>`

示例：

```
ls /aaaaaaaa 2> error.txt
```

------

### 3. 混合重定向（常用）

```
命令 &> 文件
```

> 💡 注：
>  正确输出和错误输出一起写入文件

------

### 4. 输入重定向

```
命令 < 文件
```

说明：

- 将文件内容作为程序输入
- 编程、脚本中常用

------

## 七、管道（piping）

### 1. 管道符 `|`

```
command1 | command2 | command3
```

含义：

- 左边命令的输出 → 右边命令的输入

示例：

```
cat /etc/passwd | tail -3
```

------

### 2. tee（三通管）

```
命令 | tee 文件
```

作用：

- **一份输出给屏幕**
- **一份保存到文件**

------

### 3. xargs（参数转换）

```
cat file.txt | xargs rm -rvf
```

作用：

- 将标准输入转换为命令参数
- 常用于 `rm`、`cp` 等命令
