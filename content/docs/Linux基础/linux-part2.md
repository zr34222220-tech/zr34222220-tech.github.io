## 一、文件与目录操作命令

### 1. 复制文件：cp

```
cp 源文件路径 目标路径
```

示例：

```
cp file1.txt /tmp/
```

#### 复制目录（必须加 `-r`）

```
cp -r /源目录 /目标目录
```

> 💡 注：`-r` 表示递归复制，否则目录无法复制

------

### 2. 移动与重命名：mv

```
mv 源路径 目标路径
```

示例（重命名）：

```
mv /tmp/file1 /tmp/file2
```

> 💡 注：
>
> - 路径相同、文件名不同 → **重命名**
> - 路径不同 → **移动（剪切）**

------

### 3. 删除：rm（慎用）

```
rm 文件名
rm -rf 目录或文件
```

参数说明：

- `-r`：递归删除目录
- `-f`：强制删除，不询问

常见写法：

```
rm -rf 文件或目录
rm -rf /*
```

⚠️ **警告**：
 `rm -rf /*` 会删除整个系统，真实环境中**绝对不要执行**

------

### 4. 隐藏文件

- 以 `.` 开头的文件是隐藏文件
- 删除时必须写全名：

```
rm .file
```

------

## 二、查看文件内容

### 1. cat —— 查看整个文件

```
cat 文件名
```

适合：**内容较少的文件**

------

### 2. head / tail —— 查看部分内容

```
head -3 1.txt    # 查看前 3 行
tail -3 1.txt    # 查看后 3 行
```

------

### 3. more —— 分页查看

```
more 文件名
```

> 💡 注：适合内容较多的文件，按空格翻页

------

### 4. grep —— 过滤关键字

```
grep 关键词 文件
```

示例：

```
grep root /etc/passwd
```

------

## 三、文件编辑器：vi / vim（重点）

> vim 是 vi 的增强版，**实际使用更推荐 vim**

------

### 1. 三种模式（必须记住）

| 模式     | 作用               |
| -------- | ------------------ |
| 命令模式 | 默认模式，执行操作 |
| 插入模式 | 编辑内容           |
| 底行模式 | 保存、退出、查找   |

------

### 2. 常用操作

#### 进入与退出

- `i`：进入插入模式
- `Esc`：退出到命令模式
- `:wq`：保存并退出
- `:q!`：强制退出不保存

------

### 3. 常用编辑命令（命令模式）

- 复制当前行：`yy`
- 粘贴：`p`
- 删除当前行：`dd`
- 撤销：`u`
- 可视化选取：`v`

多行操作：

- `3yy`：复制 3 行
- `5dd`：删除 5 行

------

### 4. 光标移动

- `h j k l`：左 下 上 右
- `0`：行首
- `$`：行尾
- `gg`：文件开头
- `G`：文件结尾
- `3G`：跳转到第 3 行

------

### 5. 查找

```
/字符串
```

- `n`：下一个
- `N`：上一个

------

## 四、查找与替换（vim）

```
:范围 s/原内容/新内容/g
```

示例：

```
:1,5 s/root/qianfeng/g
```

含义：

- 将第 1～5 行中的 `root` 替换为 `qianfeng`

------

## 五、写文件 / 另存为

```
:w /tmp/aaa.txt
```

## 六、vim 显示设置

```

:set nonu      # 取消行号
```
