## 一、磁盘与分区基础

### 1. 查看磁盘与分区设备

```
ll /etc/sd*
```

作用：

- 查看磁盘 / 分区的设备文件属性

------

### 2. 查看磁盘结构（推荐）

```
lsblk
```

> 💡 注：
>  `lsblk` 能直观看出 **磁盘 → 分区 → 挂载点** 的关系

------

## 二、磁盘分区（fdisk）

### 1. 进入分区工具

```
fdisk /dev/sdb
```

常见操作说明：

- 新建分区
- 设置分区大小：
  - `+2G`
  - `+10G`

------

### 2. 格式化分区

```
mkfs.ext4 /dev/sdb1
```

------

### 3. 创建挂载点

```
mkdir -p /mnt/disk1
```

------

### 4. 挂载分区（临时）

```
mount /dev/sdb1 /mnt/disk1
```

------

### 5. 查看挂载情况

```
df -hT
```

------

### 6. 刷新分区表

```
partprobe /dev/sdb
```

作用：

- 让系统内核立即识别新的分区

------

### 7. 卸载分区

```
umount /dev/sdb2
```

------

### 8. 分区补充说明

- 主分区最多 **4 个**
- 必须放弃一个主分区才能创建 **扩展分区**
- 扩展分区可创建多个逻辑分区用于存放数据

------

## 三、交换分区（Swap，虚拟内存）

### 1. 修改分区类型

- 在 `fdisk` 中按 `t`
- 输入 `82`（swap 类型）
- `w` 保存退出

------

### 2. 格式化 Swap 分区

```
mkswap /dev/sdb2
```

------

### 3. 启用 Swap

```
swapon /dev/sdb2
```

------

### 4. 查看 Swap 状态

```
free -h
```

------

## 四、逻辑卷管理（LVM）

### 1. LVM 三个核心概念

- **PV**：Physical Volume（物理卷）
- **VG**：Volume Group（卷组）
- **LV**：Logical Volume（逻辑卷）

> 💡 注：
>  LVM 的好处是 **磁盘可动态扩容**

------

### 2. 创建逻辑卷（标准流程）

#### （1）创建物理卷

```
pvcreate /dev/sdb
```

------

#### （2）创建卷组

```
vgcreate vg1 /dev/sdb
```

------

#### （3）创建逻辑卷

```
lvcreate -L 200M -n lv1 vg1
```

参数说明：

- `-L`：指定大小（M / G）
- `-n`：逻辑卷名

------

#### （4）格式化逻辑卷

```
mkfs.ext4 /dev/vg1/lv1
```

------

#### （5）挂载逻辑卷

```
mkdir /mnt/lv1
mount /dev/vg1/lv1 /mnt/lv1
```

------

### 3. 扩容逻辑卷

查看状态：

```
pvs
vgs
```

扩展卷组：

```
vgextend vg1 /dev/sdc
```

扩展文件系统：

```
resize2fs /dev/vg1/lv1
```

------

### 4. inode 与 block

- **inode**：影响文件数量
- **block**：影响文件大小
- inode 本身也会占用内存

## 五、软件链接（Link）

### 1. 符号链接（软链接）

```
ln -s /file1 /home/file11
```

特点：

- 类似快捷方式
- 可对文件和目录
- 记录的是**源文件路径**
- 源文件删除后，链接失效

------

### 2. 硬链接

```
ln /file1 /file11
```

特点：

- 必须在 **同一分区**
- 不能对目录
- 删除源文件后，内容仍存在

------

## 六、RAID 磁盘阵列

### 1. 创建 RAID5 阵列

```
mdadm -C /dev/md0 -l5 -n3 -x1 /dev/sd{b,c,d,e}
```

参数说明：

- `-C`：创建 RAID
- `/dev/md0`：RAID 设备名
- `-l5`：RAID5
- `-n`：成员磁盘数量
- `-x`：热备磁盘数量

------

### 2. 格式化与挂载 RAID

```

mkfs.ext4 /dev/md0
mkdir /mnt/raid5
mount /dev/md0 /mnt/raid5
```
